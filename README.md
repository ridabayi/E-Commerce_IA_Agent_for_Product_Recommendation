# 🛒 E-Commerce AI Agent for Product Recommendation

## 📖 Project Overview
This project is an advanced **AI-powered recommendation system** designed for e-commerce platforms.  
It leverages **Large Language Models (LLMs)**, **vector databases**, and **cloud-native deployment** to deliver highly accurate and contextual product recommendations.

The system is architected with modern **MLOps practices** to ensure scalability, maintainability, and observability in production environments.

[📽️ Download Demo Video](https://github.com/ridabayi/E-Commerce_IA_Agent_for_Product_Recommendation/blob/main/Démo.mp4)

---

## ✨ Key Features
- 🤖 **AI-driven recommendations** using LLMs (Groq API, Hugging Face embeddings)
- 📦 **Context-aware search** powered by vector storage (Datastax Astra DB)
- ☁️ **Cloud-ready architecture**, built for Google Cloud Platform (VM & Kubernetes)
- 📊 **Monitoring and observability** with Prometheus and Grafana
- 🔐 **Secure operations** with secret management and container best practices
- ✅ **Code quality enforcement** through linting, formatting, static typing, testing, and analysis

---

## 🏗️ Why This Project Matters
E-commerce platforms face increasing pressure to personalize user experiences.  
Traditional recommendation engines often fail to provide **context-rich, explainable, and scalable** solutions.

This project introduces:
- **Scalable architecture**: containerized, orchestrated, and cloud-native.
- **Explainable AI**: recommendations are powered by embeddings and context retrieval.
- **Operational excellence**: built-in monitoring, CI/CD integration, and code quality gates.

---

## 🌍 Use Cases
- Personalized product recommendations in online stores
- Contextual chatbot shopping assistants
- Intelligent search and retrieval systems for e-commerce catalogs
- Integration with customer-facing applications (web/mobile)
